# Saved agent candidate review

Custom Agent and Hire review share an accessible, read-only view of the saved
candidate version. It includes responsibility and accountable owner, identity,
all six structured instruction fields, individually resolved knowledge sources,
each proposed capability decision, memory, delegation, runtime selection,
audience and every representative scenario. Empty capability selections remain
Not allowed. A selected runtime is not presented as current if the current
resource response cannot confirm it.

The view receives the parent's current authoring admission and saved receipt.
It never substitutes unsaved editor content for the tested candidate. Resource
names are used only from a successful response that is not being refreshed;
unresolved owners and sources remain explicitly unresolved. React text rendering
escapes authored values. A changed production baseline requires a fresh revision.

The review performs no writes, model calls, grants, publication or activation.
The Custom test editor also preserves other saved scenarios when editing one,
and permits explicit addition/removal within the existing ten-scenario limit.
Changed scenarios require saving and fresh representative-test evidence.
Publication remains blocked until native policy mapping and an identified
production revision are implemented and qualified. The implementation does not
claim a before/after diff for fields whose canonical historical owner has not yet
been resolved.
