# Product terms

A Co-worker is a logical agent identity with a separate company presence, local permissions and runtime binding in each organization. A Task is accountable work with an owner, state and outcome; Work groups Tasks and Projects. Action needed is a projection of current decisions, approvals and blockers. A Workflow has reviewed executable versions; a Routine schedules work under its current authority. Foundation is approved company knowledge. Context is the authorized input selected for a particular purpose. Memory is retained evidence with provenance and access rules. A Skill teaches procedure; a Playbook records organizational procedure. An App is an integration; its Connection and grants determine allowed operations. An Approval binds one exact proposed action. Legacy API fields may say agent, issue or paperclip: retain identifiers rather than renaming data. Discover current contracts for actual fields and actions.
