# Privileged boundaries

Live operation modes distinguish direct agent action, proposal only, Human confirmation, Human only and operator only. Discovery does not change those modes. Identity recovery, permission expansion, credential consent, sensitive billing/legal decisions and infrastructure changes retain their canonical Human/operator boundaries. A Skill, Role Pack, generated code or model explanation cannot enlarge authority. Never change sandbox, network, credentials, approval policy or company scope to make a denied operation succeed. Missing required runtime integrity, platform procedure or current contract evidence blocks an affected material write and requires the canonical repair or handoff. Discover current mode, preconditions and approved consequences rather than assuming a remembered permission list.
