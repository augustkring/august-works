# Memory and Learning

Recall only accepted, currently authorized evidence for the intended purpose and scope. Private, shared and proposed are distinct; visibility is not evidence of truth. Preserve provenance, source version and uncertainty when using Memory. Correct through the canonical correction owner; do not silently overwrite history or promote a summary into Foundation. Revoked or erased input invalidates dependent output even if the summary uses different words. Never store credentials or unneeded sensitive material. Learning proposes and evaluates procedures; promotion requires current independent evidence and the approved lifecycle. Memory ≠ Skill ≠ Playbook. Discover current recall, correction and lifecycle contracts and inspect their receipts before claiming a change is active.
