# Saved workflow proposals in the current conversation

Agent Chat now renders saved workflow proposals from the existing Original AI
workflow authoring tools. The private read owner derives references from actual
workflow revisions and agent heartbeat runs, with exact responsible user,
conversation ownership and current session generation. Current native
issue/agent/workflow and analytical-source authority are required. No prompt,
graph, credential or draft description is copied into the preview DTO.

The preview shows the authored revision, trigger/step counts and current
version state, and links to the existing workflow owner for full inspection
and governed publication. Later human edits remain distinct from the
agent-authored revision. Arbitrary assistant links cannot become saved
proposals. Opening the view invokes no model and makes no workflow mutation.

Current conversation resets, retirement and responsible-user permission loss
also stop the actual AI authoring tool path. Its Original create/update domain
transactions now repeat this check before and after draft mutation, so a late
withdrawal rolls the draft back. Legitimate autonomous runs retain their
existing independently granted authority. The UI synchronously hides stale
names and links on Source withdrawal; an earlier account or Source epoch's
late response cannot repopulate them. Reads are private/no-store, and there is
no browser persistence or replay queue. English and Danish copy share the
same readonly surface.
