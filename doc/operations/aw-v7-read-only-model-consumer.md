# August Works V7 read-only model consumer

Date: 2026-10-05. The existing supervisor's leased `START_VERIFIER` delivery can now run one independently assembled, text-only Anthropic Messages assessment. Its existing accountable human interaction follows the assessment. The worker's process, session, provider response and self-rating are not the reviewer. Model results never certify a Task, approve high-impact work, or become human reviews.

The optional SaaS settings are `AW_READ_ONLY_MODEL_PROFILES_PATH` and `AW_READ_ONLY_MODEL_PROFILES_SHA256`. They must be supplied together. The absolute file must belong to the server user, have no group/other permissions, be at most one MiB, and match the deployment-pinned SHA-256. It contains at most twenty profiles, one per native company, using the strict schema in `server/src/services/orchestration/read-only-model-profiles.ts`. There is no request-controlled profile, URL or credential field. Missing configuration leaves provider inference inactive.

A profile names an existing independent Claude reviewer presence and an explicit installed Anthropic API-key grant from the existing AI Connections system. Human audience, active company membership, current connection/grant status, installation and encrypted secret version remain authoritative. Subscription credentials and responsible-user default routing are outside this contract. The profile contains an exact model revision, USD tariff ceiling, bounded complete request envelope and output, current source SHA, protected qualification artifact reference and digest, independent calibration hash, and qualification times. Qualification expires in at most twenty-four hours. Loading a file validates deployment pins and evidence metadata; it does not perform live calibration, authenticate referenced artifact bytes, prove vendor pricing, or create customer qualification. Operators must obtain that evidence before configuring an actual account.

The qualified input token ceiling must cover the complete serialized Messages request, provider framing and all billed input categories for the exact model and envelope limit. An advertised context window or a character-count estimate is insufficient. The quote must also cover all possible charges under the declared request contract. The transport forces standard service, has no tools, attachments, thinking, cache request, stream, user URL, redirect or automatic retry. It uses the existing public DNS-pinned transport at `https://api.anthropic.com/v1/messages`, a fifteen-second response/idle deadline, five-second connection deadline, thirty-second total ceiling and bounded response bytes. A changed model, truncated response, unexpected tool/content, cache charge, service tier, token usage or credential echo is inconclusive and retains the debit. Provider/socket/parse errors become fixed codes; raw errors and response bodies are not persisted or logged.

The original human, native Task/contract/output/source state, reviewer configuration, explicit account, secret version, price and deployment pins are checked before reservation, before dispatch, after credential resolution, during inference and before publication. Private agent Memory and confidential/restricted Memory are not sent through this consumer. The independently assembled evidence is bounded without silently truncating required evidence. An in-flight revocation abort is best effort; it cannot undo a request already received by the vendor. Future requests recheck native authority, and each reservation can dispatch only once.

Migration 0380 binds model assessments in the existing `verification_runs` table to a completed native model reservation. Model rows cannot have result `pass`, claim human approval, swap the spend reference or complete a Task through the native completion guard. A positive semantic recommendation becomes `needs_human`; deterministic failures remain failures. Raw model rationales and uncertainties are omitted; generic uncertainty labels and criterion/reference metadata suffice for audit. Erasure retains the existing native privacy behavior. The UI identifies model assessments and leaves every human acknowledgement unchecked.

Read-only calls consume the existing finite cumulative verifier-call/depth allowance. Nullable monetary caps remain supported for these calls, with finite qualified per-call ceilings; explicit monetary caps are enforced when present. Worker calls still require an explicit cost cap in the reservation primitive. Reservations, expired preflights and unknown dispatches never refund the native debit or restore a call slot. Reservation expiry runs in the existing bounded safety sweep independently of flags and profile configuration.

Failed, high-consequence or unknown assessments pause the native plan and enqueue its existing generation/session-scoped Stop mechanism. An expired/unavailable profile falls back to an accountable human request and pause, without provider spending or delivery retries of the model call. An accepted Stop request is not physical termination. Owner revocation, source change and rollback do not reopen a request.

Local tests exercise the actual PostgreSQL ledger, encrypted vault, grants/installations, supervisor lease delivery, late revocation, source change, incomplete canonical worker outcome, usage overflow, replay, human fallback and native completion guard. The transport is injected only in these fixtures. No vendor call, billed-token qualification, live calibration, customer work or physical runtime is claimed.

`purposes` explicitly identifies the independently qualified review purposes: `read_only_verification`, `read_only_trajectory`, or both. A profile that omits it retains verification only. Enabling verification therefore does not silently qualify or activate automatic trajectory observation. Both consumers require their current native gates and a current original human; trajectory also requires supervision and reserves from the same finite assessment allowance.

Automatic trajectory observation uses the existing supervision interval and leased intervention queue. It queues only newly observed saved outputs when deterministic arbitration permits continued running work and the finite assessment budget remains available. Each checkpoint pins the exact native plan version and authorized result packet, expires within two minutes and uses a stable spend identity across delivery retries. Pending checkpoints count against the remaining queue allowance. Expired checkpoints, changed output, unavailable qualification and late revocation pause the plan and enqueue native Stop; they cannot resend a provider request already claimed.

Trajectory results cite authorized observed evidence and normalize to `on_track`, `off_track`, `uncertain` or `possible_completion`. The existing deterministic arbiter owns the effect: on-track has no runtime effect; wrong-objective/uncertain results pause for accountable human resolution; possible completion requires passing native deterministic checks, zero live attempts, available depth and a remaining verifier call before an independent `START_VERIFIER` job is eligible. That job uses a separate native reservation and still leaves completion to the existing human review. No model result may resume, retry, spawn, reassign, approve or finish. Native migration 0381 binds each immutable trajectory signal to a completed company/plan-scoped trajectory reservation and rejects spend-reference swaps or invented certification. Only hashes, bounded criterion/reference metadata and normalized labels are retained; raw rationales and hidden reasoning are omitted. The board shows model trajectories as advisory and lets the human choose the shared assessment limit.

The scoped server consumers do not implement OpenShell's workload credential proxy, binary binding, native workload prepare/apply/start or the worker CLI gateway. Those remain explicit build work. The worker plan-start/admission cost-cap checks remain closed until every worker model call is forced through its qualified broker. The integrated pilot remains unqualified.

Native plan erasure clears model trajectory evidence references and normalized assessment facts and immediately expires those signals. The immutable native reservation reference, conservative spend and receipt hash remain for bounded financial reconciliation; they cannot authorize a new dispatch or Task completion.

Protocol references: [Anthropic Messages API](https://platform.claude.com/docs/en/api/messages), [official TypeScript Messages contracts](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/src/resources/messages/messages.ts), and the repository's existing [AI Connections](../connections/AI-CONNECTIONS.md). The public protocol is not evidence that an operator's particular account/model/price/evaluation is qualified.
