# Hire required procedural components

Hire preparation resolves every required Skill component through the Original
company Skill/version owner, matching its exact immutable release digest. The
selected active version must be explicitly consumed by the package's reviewed
Role Pack. A component-list entry alone cannot add untested instructions.
Missing, ambiguous, unauthorized or unbound components block preparation.

The same reviewed components are installed on the inactive Agent, included in
the Native Safe Test's required-procedure snapshot and retained in the actual
package installation. No optional catalog procedures or executable grants are
introduced. The confirmation lists each exact component name/revision in a
bounded accessible scroll area.
