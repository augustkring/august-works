# Representative agent draft tests

V9 section 79 requires execution evidence separately from runtime qualification,
and human verification separately from successful model execution. This change
adds the bounded internal-text path for a saved creator-owned candidate.

The initiating human reviews the immutable candidate, scenario, runtime pins,
model provider and model, USD ceiling and company-visible result before approving
a C3 command. The confirmation explains that saved candidate text and the scenario
are sent to that configured model. Expected scenario and actual output appear
together in the result.
The private installed controller owns the model, credential, price qualification
and fixed text-only transport. It grants no tools and does not activate an agent.
Knowledge, persistent memory and other capability transports remain unavailable.

Execution uses actual heartbeat runs, hidden company tasks, completion contracts,
orchestration plans and model reservations. Immutable test rows only correlate
these original records; they do not own outcome, verification or financial state.
Document ID, revision and content hash pin the generated result. Canonical human
review must cover the exact evidence packet and every contract criterion.
Candidate, configuration, profile, credential, contract or result changes withdraw
qualification. A successful model call cannot certify itself.

Permanent request identities prevent another dispatch after replay or a lost
reply. The ordinary heartbeat reaper recognizes original test correlations and
reconciles an expired deadline without repeating a call. Dispatch ambiguity
retains the Native model debit. Company and agent hard stops count retained
maximum exposure alongside their existing cost records, without double counting
or claiming an actual provider invoice. Company admission locks and SQL guards
serialize reservation admission against the same remaining budget.

The correlation retains opaque creator and draft identifiers after private draft
or account payload erasure. Removing those payloads must not cascade into the
financial reference or erase permanent request identity while the company exists.
The original reservation and cost owners still own financial state. An expired
installed price qualification blocks further dispatch and withdraws qualification
without making retained test history unreadable.

Custom Agent and Hire use one shared host component. Unresolved identity,
rollout, saved state and parent admission hide actions and late acknowledgements.
Reload recovery reads the original command; it never automatically posts it.
English and Danish copy explain cost, sharing, execution and independent review.
