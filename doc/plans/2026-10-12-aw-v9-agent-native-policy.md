# Instruction-only authored runtime policy

The identified Native instruction definition also constrains actual context
acquisition. Its current mapping uses only the authorized current Task. Foundation,
shared/private memory, cognitive/derived memory and connected-source providers
are excluded before retrieval. The context manifest records that narrowing.
Legacy agents keep their existing source selection and policy hashes.

Both the V5 runtime fabric and Native fallback carry the boundary. Authored
versions cannot acquire delegated company scopes, additional Role Pack behavior,
Skills, Playbooks or MCP bindings under this mapping. A changed or unavailable
identified definition fails closed. The transport remains the existing one-call
internal-draft controller; no model-controlled grants or action dispatcher is
introduced. Broader choices still require their specific canonical mappings.

Qualification is pending. The PostgreSQL check uses the actual context engine
and authorized Task. Instrumented persistent-memory factories throw if opened;
a positive control verifies that those hooks detect the ordinary broader path.
These software checks do not enable publication/activation or qualify live
provider, full integrated-branch or GA release behavior.
