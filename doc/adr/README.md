# August Works Architecture Decision Records

These ADRs record architecturally significant decisions for the V4 unified platform.

Every consequential ADR records context, decision, alternatives, affected qualities, trade-offs, assumptions, reversal cost, evidence, and review triggers. Do not create ADR bureaucracy for trivial implementation details.

If implementation evidence conflicts with an accepted V4 decision, update or supersede the ADR in the same coherent change. Do not silently redefine a V4 invariant, state machine, authority boundary, trust boundary, or security guarantee.

V7 decisions are collected in [V7 architecture decisions](V7-ARCHITECTURE-DECISIONS.md), with proposed contracts for later waves and explicit provider/assurance qualification gates.
