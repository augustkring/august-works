# Required procedural instructions in the text-only candidate mapping

The existing Role Pack and Skill version owners supply every required procedure
to both representative tests and identified production versions. This mapping
loads all required procedures together, including task-relevant requirements,
under a bounded text-only envelope. It selects no optional catalog content,
reads no mutable host Skill paths, installs nothing, grants no executable tools,
and refuses Playbook-derived or learned procedures until their source-context
mapping exists. Additional Role Pack item types remain blocked.

The test review lists required procedures before cost/sharing consent. The
candidate's model authority includes the exact Role Pack requirements, version
pins and procedure body hashes. A newly installed authored definition can carry
the same procedural snapshot hash. The runtime inventory, content-addressed
Skill assets and model broker recheck those exact sources. Current revocation,
replacement or missing source cannot be hidden by a previously admitted bundle.

Representative tests retain their actual Skill pins through the Original
execution inventory and Task-only Context owners. Their existing source
tombstones and erasure outbox cover those copies; no parallel Source registry,
execution authorization, outcome certification or financial ledger is added.
The model debit remains with its Original owner when copied payload is erased.
