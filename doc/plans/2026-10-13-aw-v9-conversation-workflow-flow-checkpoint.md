# Inspect the saved workflow flow in conversation

The conversation proposal can now expand its exact authored workflow revision.
The existing Original workflow review projector supplies bounded native flow
ordering, operation declarations, possible effects, approval checkpoints and
connections. Historical or discarded revisions retain their actual identity;
the flow projection does not invent a current or published version state.
The regular Workflow review still enforces its original current version binding.

When a user later edits the current draft, the existing Original structural
comparison matches actual node IDs, compares private values in process and
returns only structural changes. Private configurations, expressions, prompts,
actor assignments and credentials remain omitted. Oversized, cyclic or dangling
flows are unavailable. A missing preview on an older API response is unavailable;
it is not an empty complete flow or an unchanged comparison. The private client
checks the exact authored ID/version, complete node count and topology references.

English and Danish previews preserve the distinction between a declared approval
checkpoint and an actual approval decision. They make no model or mutation call.
The existing workflow owner remains the destination for test, edit, access and
governed publication. The current account/conversation/Agent/generation and
Source-epoch suppression also covers expanded private content.
