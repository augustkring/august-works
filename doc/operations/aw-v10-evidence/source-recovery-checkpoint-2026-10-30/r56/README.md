# R56 recovery checkpoint

Private, recovery-only archive of the latest frozen source candidates after R55. It is not a qualification, activation, publication, merge, or release claim. Candidate statuses and exclusions are in `capture-plan.json` and `manifest.json`.

The archive stores actual file bytes with source alias resolution recorded. Use the per-file SHA-256 entries to check a recovered source tree. It contains no runtime/dependency/build payloads, logs, raw database data, provider packs, or secrets.
