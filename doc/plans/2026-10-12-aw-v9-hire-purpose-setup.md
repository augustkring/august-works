# Guided approved purpose and package setup

The Hire review can select an existing approved company use case whose intended
purpose matches the exact installed package release. The completed current
representative test remains a prerequisite. Human confirmation separately
acknowledges that purpose and the package activation; the Original package
update and activation compose in one transaction. Failure rolls back both.
Governance approval, access grants, runtime creation and Agent publication are
separate owners and are not performed by this setup.

The Original private draft retains a request reference and advances its save
version without changing its candidate body. The Original activity owner keeps
the confirmation receipt. Exact replay returns that receipt; an unknown reply
retains a scoped command identity and offers only explicit receipt reads.
Account, company, saved-version and authoring-authority checks remain required.
