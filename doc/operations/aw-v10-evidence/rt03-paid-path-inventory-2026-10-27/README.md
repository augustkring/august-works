# RT-03 paid model path inventory (2026-10-27)

This is a source-owner inventory, not a deployment or provider qualification claim. It separates server-managed reservation paths from legacy bring-your-own-credential execution. The live request boundary is the callback immediately before the transport's actual `fetch`; it persists a body-free receipt containing the reservation and request identity, fixed endpoint, method, and exact serialized body digest. No headers, credentials, or prompt bytes are retained in the receipt.

The schema change is migration `0553_cute_thor_girl.sql`, generated from the current Drizzle schema. It adds nullable receipt columns to the two existing ledgers, not a new billing registry. The migration guard makes a receipt immutable after it is set, binds its reservation/request/endpoint/body digest and call-ID shape to the row, and blocks new completion transitions without a receipt. Existing terminal rows are not rewritten. The shared reservation service rechecks the current original authority and quote under its existing transaction locks before recording a receipt. The request callback awaits that transaction, so persistence/current-authority failure prevents the provider fetch.

## Non-inference checks and legacy paths

CLI credential setup/doctor checks now use the provider's model-inventory GET endpoint for key validation rather than spending an inference token. OpenRouter and other model catalog GET requests are inventory reads, not inference calls.

Runner execution profiles still include direct BYO/OpenRouter CLI, ACPX, Codex, and Anthropic Managed Agents API execution lanes. Those provider calls do not flow through the server's reservation/wire-receipt boundary, so they cannot claim the managed budget and exact wire guarantees listed above. The managed OpenCode gateway admits only its qualified Anthropic server transport and holds budget/source authority there. No automatic reconciliation or retry was added to the legacy lanes in this change; their explicit BYO execution remains outside managed hard-budget qualification.

This inventory does not establish that every optional provider is qualified, nor that any physical sandbox target passed its qualification suite.
